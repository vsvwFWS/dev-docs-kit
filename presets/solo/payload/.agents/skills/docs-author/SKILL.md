# 開発ドキュメントの作成・編集

## 対象と規約を選ぶ

`docs/index.md` から関連文書を確認し、[共通規約](../../../docs/_conventions.md)を読みます。既存の正本を編集するか、新しい文書が必要かを判断します。

詳細資料を一括で読み込まず、共通規約の案内から作業に該当する資料・節だけを読みます。同じ作業中に既に確認した規約を繰り返し読む必要はありません。

- 新規作成：メタデータガイドと種別ガイドの対象種別の節を読みます。現行仕様はspec、変更案はplan、重要な設計判断はadrを選びます。
- 既存本文の編集：共通規約を適用し、メタデータ・リンク・状態・図などを変更する場合だけ該当詳細へ進みます。
- ADRの置き換えやplanの完了：種別ガイドの対象節を参照します。ID・リンクも扱う場合はメタデータガイドを確認します。

## 執筆と確認

テンプレートは新規作成や構成の見直し時に `docs/_templates/` の対象種別だけを参照します。編集内容に応じてindex冒頭の案内やoverviewの機能一覧も整えます。

更新後は共通規約の「更新後の検証」を実行し、エラーを解消します。変更内容・根拠・未確認事項・実行した検証を報告します。
