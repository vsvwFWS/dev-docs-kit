# 既存文書の段階的な取り込み

既存文書を取り込む初期整備・移行時だけ参照します。

既存ファイルを一括上書き・移動せず、依頼範囲に従い、今回取り込む文書と当面保持する文書を整理します。取り込む文書は元の意味を保ってメタデータ・状態・リンクを整え、重複する説明の正本を決めます。

## 対象外一覧

`_config.json` の `excludedFiles` に、まだ管理対象にしない既存Markdownをdocs相対パスで個別指定します。既定値は空配列です。

```json
{"excludedFiles": ["legacy/setup.md", "old-design.md"]}
```

ワイルドカード・ディレクトリ・docs外のパス・index.mdの指定はできません。除外文書はそのまま保持され、メタデータ検証・自動一覧・IDグラフから外れます。通常の本文リンクで参照でき、リンク先ファイルの存在は検証します。取り込む際はメタデータを整えてから対象外一覧から外します。

既存設定を保持し、取り込んだファイルだけ一覧から外します。別用途の `_config.json` がある場合は上書きせず、移行方針を確認します。

## 既存目次の統合

indexは入口として取り込むため除外できません。既存の本文を保持して必要なフロントマターと自動一覧マーカー（`<!-- docs-index:start -->` / `<!-- docs-index:end -->`）を統合します。自動生成範囲の外の案内を保持し、実在する文書だけへリンクします。

取り込み時も [メタデータ](./metadata.md) と [種別ガイド](./document-types.md) の対象種別を必要に応じて確認し、更新後は [共通規約の検証](../_conventions.md#更新後の検証) を行います。
