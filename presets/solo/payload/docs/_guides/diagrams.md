# 図・画像・表

図・画像・大きな表を作成または変更するときに参照します。

- フロー・シーケンス・状態遷移・ER・簡易構成図はMermaidコードブロックを基本とします。記号を含むノードラベルはダブルクォートで囲みます（例：`A["処理 (補足)"]`）。
- 人間がレイアウトを細かく調整する図は `docs/assets/<name>.drawio.svg` に保存できます。AIが叩き台を作る場合はMermaidを使います。
- 画面キャプチャや外部資料の画像はPNG / WebPを `docs/assets/` に置き、本文から相対パスで参照します。仕様はテキストを正本とし、画像は補助に使います。
- 比較・項目一覧はMarkdownの表を使います。長いセルは文章や節へ戻し、50行を超える一覧はCSVやYAMLへの分離を検討します。
