# ログインの確認手順

例示サービスのログインを確認する手順です。起動済みの開発環境と、作成済みのテストアカウントを前提とします。

1. ログイン画面でテストアカウントのメールと正しいパスワードを入力する。
2. 自分のメモが表示されることを確認する。
3. ログアウト後、不正なパスワードでログインを試し、共通のエラーメッセージが出ることを確認する。
4. 開発環境のセッション期限を過ぎた状態で再度メモへアクセスし、ログイン画面へ戻ることを確認する。

期待する振る舞いの正本は[仕様](../specs/login.md)です。実行日時と結果は対象の作業計画へ記録します。この文書例自体は実行済みという証拠ではありません。
