# ログイン仕様

この文書は例示サービスの現行仕様です。登録済み利用者のログインを対象とし、アカウント登録やパスワード再発行は扱いません。

## 振る舞いと利用例

登録済みメールと正しいパスワードを送ると、ログイン状態になり自分のメモを開けます。サーバーはセッションを保存し、ブラウザーへ識別子をCookieで渡します。有効期限はログインから8時間です。

メールまたはパスワードが不正なときは、存在するアカウントかどうかを区別せず「メールまたはパスワードが違います」と返します。期限切れのセッションではログイン画面に戻します。

## 継続して満たす受け入れ条件

- 正しい資格情報なら、自分のメモを閲覧できる。
- 認証失敗時は、セッションを発行しない。
- 期限を過ぎたセッションでメモを取得できない。

## 関連する理由と手順

方式の理由は[ADR](../adr/0002-server-session.md)、操作は[確認手順](../guides/login-check.md)を参照してください。試行回数の制限は[変更案](../plans/2026-10-19-login-limit.md)にあり、現行仕様には含めません。
